## 🧠 Key Concepts

### JDK (Java Development Kit)
- Used to develop Java applications.
- Includes JRE and development tools like the Java compiler (`javac`).

### JRE (Java Runtime Environment)
- Provides the environment needed to run Java programs.
- Includes the JVM and required libraries.

### JVM (Java Virtual Machine)
- Executes Java bytecode.
- Makes Java platform-independent ("Write Once, Run Anywhere").

🔑 Quick Summary Table
Keyword	|Purpose
import	|Imports predefined classes or packages.
Scanner |Reads user input from the keyboard.
public	| Makes a class or method accessible from anywhere.
class	| Defines a blueprint for a Java program.
static	| Allows a method to be called without creating an object.
void	| Indicates the method returns no value.
main()	| Starting point of every Java program.
String	| Stores text.
int	    | Stores whole numbers.
double	| Stores decimal numbers.

System.in  |	Keyboard input stream.
